Machine Learning / Personal Project

Prediksi Arah Pertumbuhan Kredit Perbankan Menggunakan Machine Learning

Proyek machine learning yang mengolah indikator makroekonomi dan perbankan untuk melakukan klasifikasi arah pertumbuhan kredit perbankan.

  • Menggunakan 119 observasi data bulanan dengan beberapa indikator makroekonomi dan perbankan.
  • Melakukan preprocessing data dan pembagian data training dan testing dengan rasio 80:20.
  • Membandingkan model Logistic Regression, Decision Tree, dan Random Forest.
  • Melakukan evaluasi model menggunakan Accuracy, Precision, Recall, F1-Score, Confusion Matrix, serta analisis feature importance.
